# الطباعة — Printing

الطباعة وحدة أساسية في التطبيق، وتعمل محلياً بالكامل: تُبنى الوثيقة كـ HTML عربي (RTL) داخل العملية الرئيسية،
ثم تُعرض في معاينة داخل التطبيق، و/أو تُسلّم إلى طابعة نظام التشغيل عبر نافذة أصلية مخفية (`webContents.print`)،
أو تُصدَّر PDF عبر `webContents.printToPDF`.

## محرّك الأوراق: غلاف + تقسيم + ترقيم

الوثيقة ليست HTML متدفقاً يتركه المتصفح يقسّم كما يشاء، بل **أوراق A4 صريحة** يُبنيها التطبيق:

```
طلب الوثيقة
   ↓
بناء المتن (src/main/printing/documents.ts)  ← بيانات SQLite المحلية فقط
   ↓
تقسيم المتن إلى وحدات (src/main/printing/paginate.ts)
   ├─ سطر جدول = وحدة
   ├─ كتلة (عنوان قسم، ملخص، ملاحظة) = وحدة
   └─ رأس يوم في الدفتر اليومي = بداية ورقة جديدة
   ↓
قياس ارتفاع كل وحدة في نافذة إلكترون مخفية (src/main/printing/render.ts)
   ├─ نفس CSS ونفس عرض الورقة ⇒ الارتفاعات مطابقة لما يُطبع
   └─ كتلة الرأس/العنوان تُخصم من الورقة الأولى وحدها
   ↓
توزيع الوحدات على أوراق (اختياري: مدى صفحات) ثم تركيب HTML بأوراق مرقّمة
   ↓
معاينة داخل التطبيق = نفس HTML الذي يذهب إلى الطابعة أو إلى ملف PDF
```

### ورقة الغلاف

كل وثيقة تبدأ بورقة غلاف مستقلة (تُلغى من مركز الطباعة بخانة «ورقة غلاف للوثيقة»):

- شريط كحلي يحمل: الشعار (إن وُجد)، المؤسسة، الولاية/البلدية، الأستاذ والمادة، السنة الدراسية، تاريخ الطبع.
- عنوان الوثيقة بخط كبير داخل شريط أبيض، وتحته سطر الفترة (التاريخ/الفصل/المدى).
- بطاقة معلومات: الوثيقة، القسم، الفصل، الفترة، السنة الدراسية.
- مؤشرات مختصرة محسوبة من البيانات نفسها (عدد الحصص، الأيام، الأقسام، التلاميذ، الغياب، التقييمات… بحسب الوثيقة).
- «محتوى الوثيقة»: بنود مختصرة من كتالوج الوثائق (`PRINT_DOCUMENT_META.description`).
- تنبيه صريح: تقرير داخلي أعدّه الأستاذ لعمله الشخصي + سطرا إمضاء.

الغلاف في ورق A4 **الأفقية** يستعمل أنماطاً مدمجة (`.sheet-cover.is-wide`: بطاقات بأربعة أعمدة، قائمة بعمودين،
مسافات مضغوطة) فلا يُقتطع منه شيء.

### الترقيم واختيار الصفحات

- كل ورقة تحمل في تذييلها **«صفحة X من Y»** حيث Y = عدد أوراق الوثيقة كاملة (الغلاف يُحتسب الصفحة 1)،
  وX يبقى **ترقيم الوثيقة الكاملة حتى لو طُبعت ورقة واحدة**: فترتيب الملف الورقي لا يتغيّر عند الطبع على دفعات.
- أعلى كل ورقة رأس مختصر (المؤسسة — الأستاذ) + اسم الورقة (تاريخ اليوم أو القسم)، ويتكرّر رأس الجدول في كل ورقة.
- من مركز الطباعة يمكن: طبع **كل الأوراق**، أو **الغلاف فقط**، أو **مدى محدّد** (من صفحة / إلى صفحة)،
  أو **ورقة واحدة بضغطة** من قائمة الأوراق المسمّاة (كل يوم من الدفتر اليومي، وكل قسم في الوثائق المتعددة الأقسام).
- مدى خارج أوراق الوثيقة لا يُفشل الطباعة: تُطبع الوثيقة كاملة بدل ورقة مشوّهة.
- الطبع يستعمل الصفحات الافتراضية في نظام التشغيل، والورقة الحقيقية تنتهي عند حدّ الورقة (`page-break-after: always`)
  مع هامش أمان 0.8 مم في الطول يمنع ورقة بيضاء زائدة بعد كل صفحة.

### الدفتر اليومي: يوم لكل ورقة

كل يوم يبدأ ورقة جديدة، فيمكن طباعة **وثيقة اليوم وحدها** (بضغطة من قائمة الأوراق في مركز الطباعة أو من زر الطباعة
في شاشة اليوم) دون أن يتغيّر ترقيم بقية الأيام. أما الأيام السابقة فالورقة الأولى من الوثيقة تحمل كتلة الملخص
(عدد الحصص/الأقسام/الغياب) ثم يبدأ اليوم الأول في الورقة نفسها.

## بنية الوثيقة

- **الأوراق:** A4 حصراً، مع `@page { size: A4 portrait|landscape }`.
- **رأس الصفحة:** اسم المؤسسة، الولاية/البلدية، الأستاذ، المادة، السنة الدراسية، تاريخ الطبع، والشعار إن وُجد.
  إن كتب الأستاذ «نص رأس الصفحة» في الإعدادات يُستعمل بدلاً من الرأس التلقائي.
- **تذييل الصفحة:** نص اختياري + اسم الوثيقة.
- **الهوامش وحجم الخط والخط:** من `print_settings`. يُبحَث أولاً عن نطاق الوثيقة نفسها (`daily-notebook`, `gradebook`, `timetable`)
  ثم النطاق العام `default` — فما يُحفظ في **الإعدادات ← الطباعة** يُطبَّق فعلاً على الوثيقة المطبوعة.
- **رأس الصفحة اختياري:** خانة «إظهار رأس الوثيقة» في مركز الطباعة تُخفي كتلة المؤسسة/الأستاذ عند الحاجة.
- **الجداول:** رأس الجدول يتكرر في كل صفحة (`thead { display: table-header-group }`)، والأسطر لا تُكسر في منتصفها.
- **الطبع الملوّن:** `printBackground: true` و`-webkit-print-color-adjust: exact` لتبقى رؤوس الجداول واضحة.

## أعمدة دفتر التنقيط المطبوع

تطابق دفتر التنقيط الورقي المرجعي:

```
الرقم │ الاسم واللقب │ الغيابات │ الكراس │ المشاركة │ السلوك │ الوظائف │
التقويم المستمر │ الفرض │ معدل النشاطات │ الاختبار │ المعدل
```

- الحد الأدنى 36 سطراً في الصفحة (`GRADEBOOK_ROWS_HINT`) حفاظاً على منطق الصفوف الورقية، وتُطبع أسطر فارغة إضافية
  لاستكمال الشبكة، وإن زاد عدد التلاميذ تُطبع أسطر إضافية فعلياً.
- يظهر أسفل الجدول تنبيه صريح: **صيغة الحساب الحالية** يحدّدها الأستاذ وليست صيغة رسمية، مع سطرَي إمضاء.

## الدفتر اليومي — ترتيب الأعمدة

```
التوقيت │ القسم │ نوع الحصة │ عنوان الدرس ومراحل سيره │ غياب │ تأخر │ ملاحظات
```

- يُرتَّب المحتوى زمنياً تصاعدياً (الأقدم ← الأحدث) كما في الدفتر الورقي.
- يُسبق كل يوم بسطر عنوان يحمل **تاريخه بالعربية مع اسم اليوم** (مثال: «الأحد 27 سبتمبر 2026»).
- سطر أعلى الوثيقة يجمع: عدد الحصص، عدد الأقسام، ومجموع الغياب والتأخر المسجّل.
- عمودا «غياب» و«تأخر» من سجل الحضور الفعلي لكل حصة (`lessonAbsenceTallies` بـ استعلام واحد)، ويُعرض «—» إن لم يُسجَّل حضور تلك الحصة.
- إن كانت الفترة فارغة تظهر رسالة صريحة توجّه الأستاذ إلى شاشة «الدفتر اليومي» بدل ورقة بيضاء.

## التصميم الملوّن للوثائق

الوثيقة ليست نصاً أسود على أبيض؛ التمييز البصري مقصود ومضبوط للطباعة (`printBackground: true` +
`-webkit-print-color-adjust: exact`):

| العنصر | التصميم |
| --- | --- |
| رأس الوثيقة | كتلة بخلفية زرقاء فاتحة (`#eef5fd`) وحدود زرقاء مع شريط علوي سميك (3px) بالكحلي |
| عنوان الوثيقة | شريط كحلي ممتلئ بنص أبيض، وتحته سطر الفترة بخلفية فاتحة |
| ترويسة الجداول | خلفية كحلية بنص أبيض، وتكرار تلقائي في كل صفحة |
| السطور | تخطيط (zebra) بلون `#f7fafd`، وعمود الرقم مظلّل |
| رؤوس الأيام (الدفتر اليومي) | شريط أزرق فاتح بحدين جانبيين |
| المعدلات | شارة ملوّنة: أخضر `#ecfdf5` عند العتبة أو فوقها، أحمر `#fef2f2` دونها، مع سطر مفتاح ألوان أسفل الجدول |
| حالات التوزيع السنوي | شارات: منجز (أخضر)، قيد الإنجاز (أزرق)، متأخر (أحمر)، لم يبدأ (رمادي) |
| الإمضاءات | سطران متقطّعان «إمضاء الأستاذ» و«إمضاء الإدارة» |

**عتبة التمييز اللوني** يحدّدها الأستاذ في مركز الطباعة (وتُمرّر تلقائياً من شاشة دفتر التنقيط أو التقارير عبر
`printLink({ threshold })`)، وتُكتب صراحة في الوثيقة حتى لا يُتوّهم أنها معيار رسمي.

## الخطوط والشكل العربي

- الخط الأساسي: **Amiri** عبر `@font-face` بمسار محلي (`resources/fonts/Amiri-*.ttf`) — لا CDN.
- **Tajawal** متاح أيضاً كخط وثائق من الإعدادات (لمن يفضّل خطاً حديثاً واضحاً في الجداول).
- عند غياب الملف يُستعمل `Traditional Arabic` ثم `Times New Roman` فلا تنكسر الوثيقة ولا يضيع النص.
- الأرقام تُعرض لاتينية واضحة (`tabular-nums`) لضمان القراءة والطباعة الصحيحة.
- كل النصوص بقيم مهروبة (HTML-escaped) لمنع أي خلل في التخطيط.

## المعاينة والطباعة و PDF

| الإجراء | الآلية |
| --- | --- |
| معاينة | `print:preview` تُرجع HTML الأوراق المرقّمة كاملاً (+ عدد الأوراق، الأوراق التي ستُطبع، واسم كل ورقة) ويُعرض في `iframe` معزول (`sandbox="allow-same-origin"`) بعرض الورقة الحقيقي وارتفاع بمقدار عدد الأوراق |
| طباعة | `print:printer` → نافذة إلكترون معزولة تُحمَّل من ملف محلي (تظهر للمستخدم: معاينة/حوار الطباعة ترسمان داخل النافذة، فالنافذة المخفية تعني حواراً غير مرئي) ثم `webContents.print()` بمقاس A4 والاتجاه المطلوب و`printBackground: true` وبخطوط `file://` المحلية، وتُغلق النافذة تلقائياً بعد الحوار |
| حفظ PDF | `print:pdf` → نافذة إلكترون مخفية معزولة (`offscreen`, `sandbox`) → `printToPDF` بمقاس A4 وهوامش `none` واستعمال `preferCSSPageSize` |

### سياق الطباعة من كل شاشة

كل زر «طباعة» في التطبيق لا يفتح مركز الطباعة فارغاً، بل يمرّر سياق الشاشة عبر المسار (`printLink()`):

| الشاشة | الوثيقة | السياق الممرَّر |
| --- | --- | --- |
| الدفتر اليومي | `daily-notebook` | المدى المعروض + القسم المختار |
| صفحة اليوم | `daily-notebook` | تاريخ اليوم + قسم الحصة |
| دفتر التنقيط | `gradebook` | القسم + الفصل |
| الحضور والغياب | `attendance-log` | القسم + المدى |
| الجدول الأسبوعي | `timetable` | — |
| الأقسام | `class-list` | القسم |
| الفروض والاختبارات | `events` | الفصل |
| التوزيع السنوي | `annual-plan` | الفصل |
| الأرشيف | `teacher-report` | — |

وفي مركز الطباعة أزرار مدى سريعة (**اليوم / هذا الأسبوع / هذا الشهر / آخر 30 يوماً**) وخانة «إظهار رأس الوثيقة»،
ولا يُسمح بإرسال وثيقة ناقصة (تقرير تلميذ بلا تلميذ مثلاً): يظهر تنبيه واضح بدل ورقة فارغة.

## إعدادات الطباعة

من: **الإعدادات → الطباعة**: نطاق الإعدادات، نص الرأس، نص التذييل، الهامش (مم)، حجم الخط، خط الوثائق،
الاتجاه الافتراضي، إظهار الشعار، ومسار شعار خاص بالنطاق.

## ما لا تفعله الوثائق

- لا تُكتب عبارة «وثيقة رسمية لوزارة التربية» أو أي ادعاء رسمي غير مثبت.
- التقارير موصوفة صراحة بأنها **تقرير داخلي أعدّه الأستاذ لعمله الشخصي**.
