# الأمان والخصوصية — Security & Privacy

## إعدادات إلكترون

```ts
webPreferences: {
  preload: join(__dirname, '../preload/index.js'),
  contextIsolation: true,   // ✅ لا مشاركة كائن window بين العمليتين
  nodeIntegration: false,   // ✅ الواجهة لا ترى require ولا process
  sandbox: true,            // ✅ عملية renderer معزولة على مستوى النظام
  webSecurity: true,
  spellcheck: false,
  devTools: isDev           // أدوات المطوّر في التطوير فقط
}
```

- `setWindowOpenHandler` يمنع فتح أي نافذة جديدة، ويفتح الروابط الخارجية في المتصفح الافتراضي فقط.
- `will-navigate` يمنع أي تنقّل خارج نطاق التطبيق (`file://` في الإنتاج، `http://localhost` في التطوير).
- سياسة CSP في `src/renderer/index.html`:

```
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline';
img-src 'self' data: file:; font-src 'self' file: data:; connect-src 'self'
```

النافذة المستعملة لتوليد PDF تعمل بإعدادات معزولة أيضاً (`offscreen`, `sandbox: true`, `nodeIntegration: false`),
وتُدمَّر ويُحذف مجلدها المؤقت بعد الانتهاء.

## ما تكشفه الواجهة

`contextBridge.exposeInMainWorld` تكشف كائنين فقط:

1. `window.api` — مبني من عقد القنوات (`src/shared/ipc.ts`)، كل دالة تستدعي قناة واحدة معرّفة.
2. `window.notebookEvents` — اشتراك واحد بإعادة التحميل بعد الاستعادة.

لا يُكشف أي من: `fs`, `path`, `child_process`, `better-sqlite3`, `electron` ولا أي دالة عامة تنفّذ SQL.

## التحقق من المدخلات

- كل قناة IPC مرتبطة بمخطط **Zod** (`src/shared/schemas.ts`).
- أمثلة على ما يمنعه التحقق: علامة أكبر من العلامة القصوى، تاريخ غير صالح، وقت بصيغة خاطئة، معرّف غير موجب،
  جنس بقيمة غير مسموحة، حالة حضور غير معروفة، فصل خارج 1..3، نص يتجاوز الحد الأقصى.
- **لا SQL خام من الواجهة**: كل الاستعلامات مُعدّة مسبقاً في طبقة repositories، والمعاملات تُربط كقيم لا كنص SQL.
  طبقة الربط تُبقي فقط المفاتيح التي يحتاجها الاستعلام فعلاً، فلا يمكن حقن حقول غير متوقعة.

## معالجة الأخطاء

- أخطاء SQLite الخام لا تُعرض للمستخدم؛ تُترجم إلى رسائل عربية: «تعذر حفظ البيانات. يرجى التحقق من المعلومات.»،
  «توجد قيمة مكررة…»، «لا يمكن تنفيذ العملية لوجود بيانات مرتبطة.»
- التفاصيل التقنية تُسجَّل محلياً في `userData/logs/app.log` (مع تدوير عند 2 ميغابايت) ولن تُرسل إلى أي مكان.

## الخصوصية

| البند | الحالة |
| --- | --- |
| Cloud / SaaS | لا يوجد |
| Analytics / Telemetry / Tracking | لا يوجد |
| Firebase / Supabase / Atlas / REST | لا يوجد |
| إرسال بيانات التلاميذ | لا يحدث مطلقاً |
| المرفقات | تُحفظ كمسارات محلية، ولا تُنسخ ولا تُرفع |

بيانات التلاميذ حسّاسة، لذلك يجب الاحتفاظ بالنسخ الاحتياطية في مكان آمن ومشاركة الجهاز بحذر.

## قفل PIN — وحدوده

- الرمز يُخزَّن كبصمة `scrypt` مع ملح عشوائي 16 بايت، ويُقارَن بـ `timingSafeEqual`. الرمز نفسه لا يُخزَّن ولا يُسجَّل.
- القفل يمنع فتح الواجهة في التطبيق.

> **تنبيه صريح:** قاعدة بيانات SQLite **غير مشفّرة**. القفل لا يحمي ملف قاعدة البيانات من قراءة مباشرة على القرص،
> ولا يمنع نسخ الملف. لا يدّعي التطبيق أي تشفير لم يتم تنفيذه.

## سجل العمليات المحلي (Audit)

يُسجَّل الحد الأدنى المفيد: نوع العملية، الجهة، المعرّف، ووصف مختصر (مثل عنوان الدرس أو عدد العلامات).
لا تُسجَّل بيانات حسّاسة غير ضرورية، والسجل محلي في جدول `audit_logs` ويمكن عرضه من الإعدادات → متقدم.
